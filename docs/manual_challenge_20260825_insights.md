## 3. 勝ちパターン（人手で実証、戦略へ実装候補）

1. **縦積みラダー**: 同型ペアを下位同型の真上に組む（例: taj ペアの直下に kyrgyz、その下に
   belarus）。1回の DIRECT で 3〜5 連鎖が確定的に発火（17手+81, 35手+109, 45手+164）。
2. **ドーム斜面シェディング**: 大玉の斜面に落として意図的に転がし、傘の下の相方へ届ける
   （81手 +194: トルクメニスタン斜面→キルギス相方→4連鎖）。転がりは敵ではなく武器。
3. **pair-on-anchor**: 大物アンカーの隣に N ペアを組む。ペア併合で生まれた駒が即アンカーと
   連鎖（22手 +121, 107手 +244）。
4. **高型の標高帯集約**: ウクライナ2枚を上下近接に置けたことが 108手のメガ連鎖
   （ウクライナ×2→カザフ×2→ロシア、8駒消滅 +294）の直接原因。
5. **パーチ駒の即回収**: margin を1駒で 2.2→0.5 に落とすパーチは、同型の垂直直撃で
   即消すのが最適（78/99手）。放置すると死因になる。

## 4. 敗着パターン（今回の死因分析）

1. **退避駒の転がり被覆**: ドーム上や壁×ドームの縁に退避させた駒が転がって
   相方の頭上を塞ぐ自爆が5回（9, 47, 55, 87, 119手）。junk 退避は「既に junk がある低い籠」
   一択。ドーム上退避は禁じ手。
2. **大玉の置き場枯渇**: 盤面 35 駒超で ウズベキスタン(r1.2) の安全着地点が消滅し、
   margin −0.5 級の博打を強制される。今回ウズベキスタンが 8 体来た。
   大玉は「来た瞬間に相方へ直撃」を最優先し、貯めない。
3. 死因: 127手目、ウズベキスタン置き場なし（全候補 margin −1.5）で赤線超過。

## 5. v727 実装候補（狭い順）

1. **[リスクゼロ] analyze_board.py:345-366 のインデントバグ修正**: reactive_pairs の O(n²)
   走査が piece ループ内側で毎回再計算（結果は正しいが約40倍遅い）。4スペース dedent のみ。
2. **[狭い] 垂直開放路 DIRECT 昇格**: 同型 target の頭上に遮蔽ピースがなく、落下経路が
   自由落下で target 頭頂に到達する場合、dist に関係なく DIRECT 扱いにする
   （§1 で 3/3 実証）。fail-closed: 遮蔽判定が曖昧なら従来 NO のまま。
3. **[狭い] gap≤0.05 の NEAR 昇格**: contact_gap ≤ 0.05 は dist 不問で NEAR。
4. **[中] パーチ駒回収ルール**: 盤上同型が「頭上開放」かつ margin < 1.5 のとき、
   垂直直撃を安全上書きより優先。
5. **[中] 退避先の転がり考慮**: 退避候補の静止位置予測に斜面シェディングを入れ、
   「相方の頭上を塞ぐ静止位置」into減点。
