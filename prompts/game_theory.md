# 戦略: 人工化学フレームワーク

## ソ連建国率を主目的とする戦略方針（2026-09-06）

本節は、依頼「ソ連建国率を上げるための施策を考えて、戦略に組み込む」に基づく方針である。分析・実装・レビューで共通に使う。詳細な基盤修正の追跡先は `azumag/soviet_now#132`。

**優先関係**: `data/mandatory_themes.txt`、デッドライン安全性、編集可能ファイル・戻り値の契約は変えない。従来の各戦略プロンプトにある「下位段階が100%になるまで上位段階を改善しない」「12試合の評価スコアが上がれば目的に近づく」という目的・優先順位の部分は、本節に置き換える。既存ランキング・rollbackの動作を無断で無効化する指示ではない。

### 1. 勝利の定義と評価の逆転を分離する

- 最終目的は **1試合中に少なくとも1回ソ連を建国する確率**。第一ロシアの作成、最大type、raw score、延命手数だけでは成功にしない。
- 建国証拠は試合IDと対応した `makeSorenCount` の増加／正の値と履歴イベント。最終盤面にtype16が残ることを必須にせず、途中の建国を最後まで保持する。試合開始時にカウンタの基準とリセットを確認し、前試合の値を持ち越さない。未観測・破損は未知であり、0件と捏造しない。
- T16の残存ボーナスがなかった旧版では、`136 + 800 - 2×12096 = -23256` の逆転があった。2026-09-07に確認したVM上の `eloop.sh` と `wildcard_parallel.py` には、T16ボーナス25,402と建国加点800が既にある。最終盤面にT16が残る場合、raw増分136を仮定した同じ局所比較は `136 + 25402 + 800 - 2×12096 = +2146` となる。「現在も必ず23,256点下がる」とは扱わない。
- これは当日のディスク上の2経路の確認であり、実行中プロセスの評価器version、T16が消えた場合や旧版履歴、rolling/regressionや全A/B判定の整合を保証しない。建国証拠が欠測なら未知のままとし、proxyや旧評価値だけで良否を決めない。
- `eloop.sh`、wildcard、rolling/regression等の共通・版付き評価への移行は #132 の基盤変更として扱う。`strategy.py.staging` とhelperだけを編集できる改善ジョブから、評価器・履歴・採否規則を変更しない。旧新の評価値を混ぜず、移行前後の比較はshadowから検証する。
- 本節の追加だけで評価器の逆転が直った、または建国率が上がったとは報告しない。次の実験の採否規則には建国実績を最優先の指標として事前登録し、旧scalar score単独による本番昇格は認めない。進行中実験の規則は途中変更しない。

### 2. 改善対象は「100%未満の最初」ではなく実際の失敗箇所で選ぶ

- 同一の戦略・helper・解析器・runner・設定で得た試合を対象に、T13、T14、第一T15、T15×2、ソ連の到達数と分母を示す。T11は自然供給された個体と併合で生成した個体を区別し、供給を作成成功と取り違えない。
- 第一T15に届かない問題、第一T15の後に第二系列が育たない問題、T15×2が接触できない問題を分ける。全試合での到達率と、直前段階に到達した試合を分母とする移行率の両方を見る。
- 下位段階の失敗削減は継続するが、少数標本の100%を上位改善の解禁条件にはしない。12/12は母集団での100%を意味しない。上位局面だけに効く候補は、下位局面の非悪化と対象局面での実効差を検証する。
- ソ連0件同士なら率の優劣は未確定。段階進捗・残留面積・露出・生存は次の仮説を選ぶ補助指標であり、建国率改善の証明ではない。

### 3. 序中盤から「消せる盤面」を保つ

- 安全な即時併合を逃さず、同時に **次の同型が実際に届く露出面と接触経路** を残す。見えているtypeの種類数だけを増やして、届かない駒や埋まったペアを数えてはいけない。
- 非併合候補を比べる際は、最後の到達可能な同型個体の被覆、T10〜T14の未処理ペアの分断、次手の落下経路の閉塞を調べる。候補自身の露出と、併合する場合の生成物もpost-stateに含める。
- 容量回復の補助指標は `relief(t) = 2 × area(t) - area(t+1)`。同じ併合1回でも解放量は異なるため、併合回数だけで候補を順位付けしない。ただし面積は近似であり、低く配置して空隙を減らす効果と併合による面積減少を区別する。
- 面積の算定元は物理形状または検証済み `TYPE_RADII` に固定する。snapshotの表示用 `r` をそのまま物理占有面積と同一視しない。面積が減る予測でも、実際の着地・併合後の上端が危険なら採用しない。
- 既存の `HIGH_TYPE_COVER_AVOID`、露出保護、レーン保護等をまず照合する。同じ目的の加点軸を重ねたり、全候補に同じ加点をして「改善した」としない。既存軸の有無ではなく、最終実行xが変わり、狙った被覆や分断が減るかを検証する。

### 4. NEXTを使って「実際に併合できる確率」を上げる

- `next` は現在落とす駒、`nextNext` は次に見えている駒として実際のstate契約を確認する。既知の駒と、その後の未知の供給分布を分ける。
- 直接供給されるtype 1〜11の一致機会と、合成して作るtype 12以上の成長経路は別評価にする。実行環境の供給範囲・分布が不明なら仮定と明記し、現行ゲームの実装・履歴で確認する。
- `nextNext` が届く既存同型や、次手で閉じられるペアの上・間に現在の別typeを置かない。安全でない次手や仮想的な連鎖だけを根拠に、現在の安全な即時併合を捨てない。
- `DIRECT` / `NEAR` や下記 `MERGE_PROB` は解析器の推定であり、校正済みの実確率と断定しない。遮蔽物、壁・回転、着地点のずれ、併合後の生成物を含めた実測で反証する。

### 5. 第一ロシアの前から第二系列を設計する

- T13/T14が育つ段階から、第一T15になった後にも素材を育てられる空間と接触経路を確保する。第一T15を作ってから空いた端へ小駒を捨て続けるだけの延命を目標にしない。
- 第一T15が1個なら、その安定位置をアンカーとし、到達可能な近傍に第二系列を育てる。大型駒を遠い左右の壁際へ分離する「二つの独立した山」は避ける。狭い盤面で無条件に左右固定するのではなく、実際の安全な接触経路で成長位置を選ぶ。
- 第二系列の素材量を評価するときは、保存対象の第一T15を除外する。例として `Σ 2^(type-11)` はT11相当の材料量で、T15には16必要。ただし同じ材料量でも、遠く分断されていれば合成可能とは限らない。
- `second_russia_lane_*`、残り素材、素材同士の接触可能性、第一T15後の生存を一緒に見る。`remaining_russia_equivalent` 等の既存フィールドを使う前に、単位と算定対象を実装で確認する。
- 第一T15生成時の残りT12〜T14、第二T14/第二T15の到達、素材が覆われたターンを記録して候補を比較する。素材温存のために安全な高type同士の併合を止めない。

### 6. T15が2個そろったら最終併合を独立した目的にする

- T15×2を実在する別個体として確認し、最終併合を最優先の局面目的とする。中心間距離だけで接触可能とせず、形状・間の駒・外側からの接触候補を調べる。
- 接触経路の被覆を避け、既存の安全な接触誘導を優先する。間接的な押し込み候補は、実在する衝突対象、方向、着地と併合後のデッドライン安全性を確認する。reason文字列を付けて安全判定を迂回しない。
- 建国を理由に危険な固定座標や無検証の強打へ切り替えない。安全な即時併合を捨てて確率不明のシェイクに賭けず、情報が足りない場合は候補や安全性を捏造しない。

### 7. 実装候補と検証・採用の順番

1. **第一候補: 到達可能な高type成長レーンの被覆削減。** 非併合候補の比較を一箇所だけ変更し、現在/次の駒が届く最後の露出、未処理高typeペア、第二系列を保つ。既存処理で既に満たされている場合は重複実装せず、履歴で支持される別の失敗箇所を一件選ぶ。
2. **第二候補: 第一T15前後の材料・空間計画。** 第一候補と同時投入しない。現行レーン制御との違いを明示し、第一T15後の第二T14/第二T15進捗を対象にする。
3. **第三候補: T15×2の最終接触。** 当該局面のfixtureを独立に確保する。希少局面を多めに検証しても、その検証標本を実戦の建国率の分母に混ぜない。

各候補は、盤面fixture → 全決定経路のshadow再生 → 同一policy bundleのA/A確認 → 事前登録A/Bの順で検証する。`decide → safety → finalizer → safety` の最終xと実際の盤面変化を確認し、reasonの発火回数だけを成果にしない。左右鏡像、危険な併合後状態、情報欠測、安全な即時併合がある局面も回帰対象とする。係数や軸の無効化実験は、変異ごとのPythonキャッシュ取り違えを防ぎ、独立再実行で再現してから解釈する。

A/Bは戦略・helper・解析器・runner・環境の識別子、分母、最大試合数、停止規則、採否・非劣性基準を事前固定する。開始した全試行を記録し、完了試合での建国率に加えてtimeout・例外・未知の件数と試行全体の結果を併記する。欠測や腕依存の失敗を黙って除外しない。途中の成績を見て終了条件を変更しない。1回の建国は実現可能性の証拠であり、率改善の断定には事前に定めた区間推定・必要標本を満たすこと。

## ゲームの本質 — 物理挙動を伴う項書き換え系

このゲームは**空間に埋め込まれた項書き換え系 (Term Rewriting System) としての人工化学**である。

項書き換え系では、記号列（項）に対して書き換え規則を繰り返し適用して計算を進める。本ゲームでは「ピース」が項、「同種併合」が書き換え規則に対応する。通常の項書き換え系との決定的な違いは、**書き換えの発火条件が物理空間上の接触**であること — つまり書き換え規則の適用可能性が空間的配置に依存する。

| 人工化学の構成要素 | ゲームにおける対応 | 項書き換え系との対比 |
|---|---|---|
| 分子種 S | type 1〜16 のピース（極度に異方性を持った粒子） | 項のアルファベット |
| 反応規則 R | `type_N + type_N → type_{N+1}` | 書き換え規則 |
| 反応器 A | 物理エンジン (重力・衝突・回転・爆発) + 箱型容器 | 書き換え戦略 + 空間制約 |
| 反応物供給 | next/nextNext のドロップ | 項の入力 |

標準的な人工化学の三つ組 `(S, R, A)` に加えて、このシステムは以下の特性を持つ:

- **空間的局所性**: 反応（書き換え）は物理的に接触したペアのみで発生。同じ分子種でも空間的に離れていれば反応不可能
- **重力による非対称性**: ピースは下方に蓄積し、上方から供給される。これが反応器の空間構造を支配する
- **爆発衝撃波**: 反応（併合）成功時に force=450, radius=2.0 の衝撃波が発生し、周囲の分子の空間配置を擾乱する。これが連鎖反応（多段書き換え）の主因
- **極度の異方性**: ピースは円ではなく国土形状の凸ポリゴンであり、極度に異方性を持った粒子。着地後に回転・転がりが発生し、最終位置が予測困難

## プレイヤーの役割 = 反応器管理者

プレイヤーはドロップX座標のみ制御可能。反応規則 R は固定されており変更できない。したがってプレイヤーの役割は**反応器 A の管理** — 反応物の空間配置を制御して反応効率を最大化すること。

これは化学工学における反応器設計問題と同構造:

```
入力: ランダムな分子種が順次供給される (next/nextNext)
制御変数: 供給位置 (ドロップX座標, -3.0〜+3.0)
目的関数: 1試合で少なくとも1回ソ連を建国する確率の最大化（スコアは補助指標）
制約: 容器溢れ (デッドライン超え) で停止
```

## 人工化学から導出される戦略原則

### 1. 濃度管理（同type集約）

化学反応速度は反応物の濃度に比例する（質量作用の法則の空間版）。同typeピースが空間的に散在すると「希薄溶液」状態となり、反応（併合）確率が事実上ゼロに低下する。**同typeピースの空間的密度を最大化する**ことが反応効率の基本。

`analyze_board.py` の `calc_reactor_state()` がこれを定量化:
- `reactive_pairs`: 接触圏内の同typeペア数（即時反応可能）
- `near_pairs`: 近接ペア（触媒操作で反応誘導可能）
- `type_count`: 分子種ごとの濃度

### 2. パイプライン維持（反応経路の接続性）

項書き換え系では `type1 → type2 → ... → type16` という書き換え列が最大得点経路。この経路が成立するには、各段階の反応物（typeN と typeN+1）が空間的に近接している必要がある。パイプラインの「断絶」は連鎖反応の停止を意味する。

`analyze_board.py` の `pipeline` がこれを監視:
- `[OK]`: typeN と typeN+1 が距離 3.0 以内
- `[WARN]`: 距離 3.0-5.0（連鎖困難）
- `[BROKEN]`: 距離 5.0 超（経路断絶、即時修復が必要）

### 3. 触媒操作（間接的反応誘発）

直接接触していなくても、小ピース投入の物理衝撃（シェイク）や併合時の爆発衝撃波で間接的に反応を誘発できる。これは化学における触媒の役割に相当する:

- **シェイク触媒**: 小ピース(type1〜4)は比較的重量がある。盤面の重量バランスが不均衡だと、ピースが重みで振動し、攪拌効果により接触を誘発
- **爆発連鎖**: typeN-1 ペアを typeN の近くに配置 → N-1 併合の衝撃波で typeN ペアも接触 → 多段連鎖
- **壁バウンド**: 壁際併合の射出で新ピースが反対方向に飛び、離れたピースと予期せぬ反応

### 4. 国側集約（空間的対称性の自発的破れ）

大型ピース (type9+) は半径が大きく移動困難。容器の左右に分散すると二度と合流できない。これは相分離（空間的対称性の自発的破れ）として理解できる: 最初の type9+ が置かれた側（国側）に以後の大型ピースを全て集約することで、高type反応の空間的条件を維持する。

国側集約は本プロジェクトで最も強い実証的根拠を持つ原則であり、49個の確定済み原則の多くが国側管理に関連する。

### 5. 連鎖設計（多段書き換えの仕込み）

項書き換え系の最大の特徴は**一つの書き換えが次の書き換えの発火条件を満たす**連鎖。ゲームでは `N-1+N-1→N` の生成物が既存の typeN と接触して `N+N→N+1` を誘発する多段連鎖がこれに対応する。

連鎖設計 = typeN-1 ペアを typeN の近くに事前配置しておくこと。爆発衝撃波による空間擾乱が連鎖の確率を高める。

### 6. 先読み併合（next/nextNext の未来予測）

next が type N の場合、盤面に type N-1 のペアがあればいずれ併合して type N が生まれる。その生成予定地点の近くに今の next(type N) を置くことで、将来の連鎖併合を仕込める。nextNext も同様に考慮することで、2手先までの期待値を最大化する。
