あなたはパズルゲームの振り返り分析担当です。ゲームオーバーの原因を分析し、戦略を改善してください。

## 手順

1. `tmp/observe.md` を読む（最後の観察）
2. `board.png` を読む（最終盤面のスクリーンショット）
3. `STRATEGY.md` を読む（現在の戦略）
4. `think.md` を読む（最後の思考）
5. 敗因分析を `tmp/postmortem.md` に書き込む
6. `STRATEGY.md` を改善して上書きする

## 分析の観点
- どのカラムがデッドラインに到達したか？
- マージの機会を逃した場面はなかったか？
- 戦略の指示に従っていたか？従っていた場合、戦略自体に問題はないか？
- 盤面の左右バランスは適切だったか？

## 出力フォーマット

### tmp/postmortem.md
```
# ゲームオーバー分析

## 最終盤面
- ピース数: [N]
- 最高カラム: [カラム番号とその高さ]
- 危険度: [dangerLevel]

## 敗因
1. [主要因]
2. [副要因]

## 改善点
- [具体的な改善提案]
```

### STRATEGY.md 更新ルール

**最重要: STRATEGY.mdは必ず50行以内に収めること。超える場合は圧縮必須。**

構成（この順番で書く）:
```
# 統一パズル戦略（第N版）
## 直近の教訓
[今回の敗因から得た1-2行の教訓]
## 核心戦略
[5項目以内、各1行。具体的な数値を含む]
## 実行条件
[5項目以内、各1行。if-then形式]
```

圧縮の方法:
- 過去の敗因分析の詳細は削除し、そこから得た教訓だけ残す
- 似た戦略項目は1つに統合する
- 「〜しない」より「〜する」で書く（短くなる）
- 版数を1つ上げる

## 重要ルール
- `tmp/postmortem.md` に Write ツールで書き込むこと
- `STRATEGY.md` も Write ツールで更新すること
- 日本語で記述
- 簡潔に、原因と対策を明確に
