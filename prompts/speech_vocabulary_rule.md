【語彙・言い回しの共通ルール】
- 丁寧な語彙を選ぶこと。トーンがカジュアルでも、語彙までくだけさせない。
- 下品・乱暴・失礼・幼い言い回しや若者言葉は使わない。
  - ×「腹がすく」「腹が減る」 → ○「お腹が空く」「お腹が空きました」
  - ×「食う」「食った」「食って」 → ○「食べる」「食べた」「食べて」
  - ×「めし」「飯」 → ○「ごはん」「食事」
  - 食べ物の味は「うまい」ではなく「おいしい」と言う
  - ×「すげえ」「やべえ」「マジで」「めっちゃ」 → ○「すごい」「大変」「本当に」「とても」
  - ×「ぶっちゃけ」「〜じゃん」「〜っしょ」「〜だぜ」「〜かよ」 → 丁寧な言い方に直す
- 体や排泄の話、下ネタ、罵倒、差別的な言葉は使わない。人や視聴者を見下す言い方もしない。
- 皮肉・強がり・ユーモア・斜に構えた表現はこれまでどおり使ってよい。変えるのは語彙だけ。
- 専門用語や業界スラングをそのまま読み上げない。読み上げて失礼に聞こえない言葉を選ぶこと。
