# Soviet Game Controller

ブラウザゲームを外部ファイルから操作するためのスクリプト。

## 起動方法

```bash
node soviet_game.mjs
```

## 仕組み

1. ブラウザを開き、ゲームを自動起動
2. `commands.txt` を監視（500ms間隔）
3. コマンドを検出すると座標をクリック
4. 操作後に `soviet_now.png` としてスクリーンショットを保存

## コマンドファイル形式

`commands.txt` に以下の形式で記述：

### 形式1: x,y 形式（1行につき1コマンド）

```
640,180
400,200
800,200
```

### 形式2: retry コマンド

ゲームオーバー時にキャンバス中央をクリックしてリトライする。

```
retry
```

### 形式3: JSON形式

```
[{"x":640,"y":180},{"x":400,"y":200},{"x":800,"y":200}]
```

## 操作例

```bash
# 単一クリック
echo "640,180" > commands.txt

# 複数クリック
cat > commands.txt << EOF
640,180
400,200
800,200
EOF

# JSONで一括指定
echo '[{"x":640,"y":180},{"x":400,"y":200}]' > commands.txt

# ゲームオーバー時にリトライ
echo "retry" > commands.txt
```

## ファイル一覧

| ファイル | 説明 |
|---------|------|
| `soviet_game.mjs` | メインスクリプト |
| `commands.txt` | 操作コマンド入力用（外部から書き込み） |
| `soviet_now.png` | 最新のスクリーンショット |

## 座標について

- Canvasサイズ: 約1280x720
- クリック位置はCanvas内に自動調整されます
